# Scenario 1 - Example Scenario One

This scenario shows the basic building blocks of a lab page: text, a screenshot and a callout.

Open the application and click **Settings** on the left menu.

![Screenshot](images/scenario-1-01.png)

!!! note
    Callouts use the admonition syntax. Other types: `tip`, `warning`, `danger`, `example`.

Enter the required value, then click **Save**. Inline code and commands use backticks: `https://<IP>:9440`.
